## Deployment

### Podman Compose

```yaml
services:
  craft-anything:
    image: "ghcr.io/daemonless/craft-anything:latest"
    container_name: craft-anything
    environment:
      - PUID=1000  # User ID for the nginx worker processes
      - PGID=1000  # Group ID for the nginx worker processes
      - TZ=UTC  # Timezone for the container
    ports:
      - "8094:80"
    # always (not unless-stopped) so FreeBSD's podman rc.d auto-starts it at boot
    restart: always
```

Save as `compose.yaml`, then run `podman-compose up -d`.

## Setup Instructions

**Everything runs in the browser.** Craft Anything is Rust compiled to WebAssembly; the container only serves static files. Files open through the browser's file picker and save as downloads, and nothing is stored server side, so there are no volumes.

**Your work lives in the browser, not on the server.** Preferences and any in-app library or cache belong to the browser profile that opened the app, per origin. Clearing site data, switching browsers, or reaching the app under a different hostname means starting empty. Export what you want to keep; the exported files are the backup, as with any desktop app.

**Fonts.** The browser build ships with JetBrains Mono, DM Sans and Geist Mono. Craft Anything also lists the Japanese, Chinese and Arabic families from [craft-fonts](https://github.com/storytold/craft-fonts), which this image serves alongside the app; a family is downloaded the first time you pick it or open a project that uses it.

**HTTPS.** WebGPU and the clipboard need a secure context. Over plain HTTP the app falls back to WebGL2; put it behind your reverse proxy for the full experience.
